# Architecture Decision Records

ADRs record durable decisions that constrain future implementation. They explain
why a choice was made, which alternatives were considered, and its consequences.

Status values are `Proposed`, `Accepted`, `Superseded`, or `Deprecated`.
Accepted ADRs are immutable except for spelling or link fixes. Replace a decision
with a new ADR that links to and supersedes the old one.
